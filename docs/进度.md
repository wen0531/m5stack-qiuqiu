## 2026-10-26 · StopWatch 线封口：多语言 + 主机模拟器

**这一段做了什么**

1. **多语言（10 种）**：子集字体方案，每语言只打包文案里实际出现的字形，固件只增 160 KB。
   语言列表：en / 简中 / 繁中 / 日 / 韩 / 法 / 德 / 西 / 俄 / 拉丁。
   文案单一来源 `tools/i18n/strings.json` → 脚本生成 C++ 表、语言枚举、字体表、字幕子集字体。
2. **启动器与子页本地化**：应用名（闹钟/表盘/秒表/球球/设置）、设置菜单、Button/时间/日期子页；
   启动器字体从无 CJK 的 `MontserratSemiBold26` 换成带 CJK 子集的 `i18nFont()`，切语言下一帧自动刷新。
3. **语言选择页**：设置里 Language 从"点一下轮换"改为打开十语言列表，每行用该语言自己的字体，当前语言高亮。
4. **主机模拟器（新）**：跑真实固件 UI（mooncake + 6 app + LVGL 9.5 + 全部资源），
   统一虚拟面板（LVGL flush 与球球 M5GFX 直写同缓冲）、输入注入、状态查询、界面元素枚举、
   崩溃/卡死监督、设备容量约束（内部 RAM 512 KB / PSRAM 8 MB / Flash 槽 4.94 MB，超限 abort）、
   网页前端（127.0.0.1:8099，实时画面 + 按键触摸 + 语言 + 状态 + 容量条 + 日志）、
   确定性模式 + 16 场景截图回归（三次运行逐字节一致）。
5. **刷机与验证**：3,417,424 B 写入 ota_0，**读回设备镜像 sha256 与本机文件完全一致**；
   BLE `StopWatch-BLE` 在线、自定义服务在位、状态 IDLE。

**过程中修掉的真 bug**

| 问题 | 影响 | 处理 |
|---|---|---|
| 空格被字体生成脚本过滤 | 所有子集字体没有 U+0020，拼字符串会出方块 | 只过滤控制字符 |
| 语言自称缺失字形 | 语言选择项自身显示方块 | 生成时纳入 `lang_names` |
| `MALLOC_CAP_SPIRAM` 位值写成 0 | 模拟器把 PSRAM 分配算成内部 RAM，球球一开就误报 OOM | 改成真实位值 |
| Kconfig choice 成员当宏输出 | 误启用 ARM NEON，主机编译失败 | 生成器排除 choice 前缀 |
| `hold` 命令不推进模拟时间 | 按键被误判已释放，打开的页面立刻关闭 | `combo` 命令内部推进 |
| 回归命令走错通道 | `simctl` 无 `step/clock` 子命令，静默失败、截图全黑 | 统一走 `raw` |
| 控制端口串用 | 上一个场景进程仍监听，命令发给了旧进程 | 每场景独立端口 |

# 宣传视频脚本（90 秒 · 12 个特点全含）

> 用途：交给视频制作者按此文本生成宣传片
> 时长：90 秒（正片 88 秒 + 2 秒留白）
> 语言：中文口播 + 中文字幕
> 事实口径：以仓库 README 为准；**不报"续航 3–4 天"，不与其他固件比毫安数**

---

## 五、制作规范

**字幕**

- 每行 ≤ 14 个汉字，最多两行；居中偏下，避开表盘圆角
- 关键词加粗：**蓝牙** / **网页** / **十种语言** / **自动退回**
- 专有名词保留原文：M5Stack、BLE、USB、MIT、Latina

**画面**

- 手表镜头**关灯拍**，AMOLED 黑底最干净；避免屏幕反光
- 手表屏幕占画幅 ≥ 60%，让球球的表情看得清
- 语言切换、B 键变色这类操作**一镜到底**，不要剪碎（观众要看到"真的立刻变"）

**声音**

- 口播语速偏慢（每分钟约 230 字），关键句后留 0.5 秒空白
- 问答段（#2）**收真实喇叭声**，不要后期配音，真实感更强
- 背景音乐：轻电子 / lo-fi，音量压到 -22 LUFS 以下，别盖过人声

**节奏**

- 前 5 秒必须出现"会说话"的画面（留住观众）
- 每 8–10 秒换一个视觉信息点
- #8（自动回滚）是情绪高潮，前后各留 1 秒静音
